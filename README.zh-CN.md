# Campus Vitae

> 一款源自校园记忆、适合专注写作与学术工作的宁静 Obsidian 主题。

Campus Vitae 以柔和的蓝白配色、克制的科学元素和大学校园景观，为 Obsidian 带来安静的学术氛围。主题支持明暗模式，并可通过 Style Settings 插件进行丰富的个性化设置。

## 特性

- 同时支持亮色与暗色模式，整体风格宁静而富有学术气息
- 内置四套配色：素、霓、霞、青
- 融合校园景观与科学元素的背景设计
- 可调节排版、内容宽度、段落间距与标题样式
- 提供多种 Callout、表格、大纲及导航样式
- 可选彩色文件夹树及 Components 插件适配
- 针对代码、属性、关系图谱、嵌入内容和学术三线表进行专门设计

## 环境要求

- Obsidian 1.12.0 或更高版本
- 推荐安装 [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) 以使用自定义设置
- [Components](https://cp.cc1234.cc/) 为可选插件，仅在使用相关组件样式时需要

校园壁纸主要面向桌面端界面设计；移动端不会显示桌面背景，但主题的其他部分仍可正常使用。

## 安装

### 社区主题市场

Campus Vitae 上架 Obsidian 主题市场后：

1. 打开 **设置 → 外观**。
2. 在主题一栏选择 **管理**。
3. 搜索 **Campus Vitae**，然后选择 **安装并使用**。

### 手动安装

1. 从[最新版本](https://github.com/UHRS-AI-Association/obsidian-CampusVitae/releases/latest)下载 `manifest.json` 和 `theme.css`。
2. 在仓库的 `.obsidian/themes/` 目录中创建名为 `Campus Vitae` 的文件夹。
3. 将上述两个文件放入该文件夹。
4. 打开 **设置 → 外观**，选择 **Campus Vitae**。

## 自定义

安装 Style Settings 后，打开 **设置 → Style Settings → Campus Vitae**。你可以在这里切换配色，并调整排版、布局、标题、表格、Callout、导航、文件夹颜色及组件样式。
